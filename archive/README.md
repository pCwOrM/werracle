# Werracle Historical Site Archives

This directory preserves historical iterations and initial deployment baselines of the Werracle web portals for version control, audit trail, and research documentation.

## Preserved Sites

- **`sites/v1_classic.html`**: The classic v1.0 initial baseline website ("Zero-Memory On-Chain AI Decision Oracle", EVM 32-Byte Slot, 20k gas).
- **`sites/v2_initial_archive.html`**: Early architecture sandbox iteration for v2.0.
- **`sites/test_site/`**: Early testbed and staging assets (`index.html`, `og.png`, `werracle-mark.png`).

> [!NOTE]
> These historical pages are strictly archived for code audit and historical preservation. They are excluded from live production builds and GitHub Pages deployments.
