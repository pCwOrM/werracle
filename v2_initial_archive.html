Werracle is an AI decision oracle that runs inside the EVM. It stores no weights. It derives them from one point on the Mandelbrot boundary, then answers allow, route or score in about 19,400 gas, inside the same transaction that asked.

A neural network can't fit in a block.

Millions of float weights would need more than 15 million gas for one inference. So today's AI stays off-chain, and contracts trust a signed message that arrives a block too late.

KBof proofs

ZK-ML proves it, slowly.

The model still runs off-chain. A prover spends 10 to 300 seconds, then the chain pays around 350,000 gas to verify. Correct, but never inside the attack's own transaction.

32bytes

Werracle stores a coordinate, not a model.

Weights are recomputed on demand from the escape dynamics of z → z² + c, in Q16.16 integers. One SLOAD reads the whole brain for 100 gas. Nothing leaves the chain.

It stops the attack inside the attack.

A flash loan borrows, manipulates and repays in one transaction. An oracle that answers next block is already too late. Werracle answers in the middle, and a revert undoes everything before it.

Guarding NEAR Intents before they are signed.

Werracle sits in front of NEAR chain signatures as a pre-signing reflex. Clean intents pass through to Base or Ethereum; sandwich and flash-loan patterns are vetoed before a signature exists. Built for NEAR Hackathon 2026, tracks Unstoppable DeFi and AI Security.

Proved, not just tested.

Add it to a contract.

    
One import, one call, one require. The guard runs before your sensitive logic, in the same transaction.

    
forge install pCwOrM/werracle

    

      
ProtectedVault.sol


// SPDX-License-Identifier: BSL-1.1
pragma solidity ^0.8.20;

import "werracle/contracts/IWerracle.sol";

contract ProtectedVault {
    IWerracle public immutable werracle;

    constructor(address oracle) { werracle = IWerracle(oracle); }

    function withdraw(bytes32 state, int64 riskQ16) external payable {
        // same-transaction decision, ~19.4k gas
        (bool allowed, ) = werracle.decideNoul{value: msg.value}(state, riskQ16);
        require(allowed, "Werracle: hostile pattern");
        // ... protected logic
    }
}
